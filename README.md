# Rack & Ledger — Premium Shopify Portfolio

A premium, responsive Shopify studio portfolio built with semantic HTML, modern CSS and vanilla JavaScript, with GSAP + ScrollTrigger for motion and Lucide for icons.

## Structure
- `index.html` — complete single-page portfolio
- `styles.css` — responsive visual system and layouts
- `script.js` — navigation, motion and interactions
- `assets/favicon.svg` — custom favicon
- `images/profile.jpg` — add your profile photo here

## Important
The only personal image slot is `images/profile.jpg`. All other visual portfolio pieces are CSS-built art-direction mockups, so the site does not depend on stock photography.

The portfolio testimonials are explicitly marked as illustrative sample feedback. Replace them with verified client testimonials as you complete Shopify projects.
